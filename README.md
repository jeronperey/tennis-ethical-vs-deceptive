# Assignment 3: Ethical and Deceptive Visualization (DATA 3302)

Question: **Do aces win matches?** Two static D3 + SVG charts of the same data, labelled A and B
(`PANELS` at the top of `visualizations.js` says which is which).

- `prepare_data.py`: data processing. Reads `data/raw/`, applies the exclusions, writes `data/processed/` and `data.js`.
- `visualizations.js`, `index.html`, `lib/d3.min.js`: the two visualizations (open `index.html` in a browser).
- `visualization_A.svg`, `visualization_B.svg`: standalone exports of each chart.
- `writeup.md`: the write-up (about 900 words). `build_submission.py` builds `submission.html` and the draft PDF from it.

Data: Jeff Sackmann, Tennis Abstract ATP match data 2015-2024 (CC BY-NC-SA 4.0),
via github.com/Aneeshers/tennis-sackmann-archive.
